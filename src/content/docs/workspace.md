## 1. まず書き置く

クイック入力で思いつきを作ります。配置先を決めなくても構いません。作成した項目は `未配置箱` で確認し、後からルートまたは選択中の項目の子へ明示的に配置できます。

## 2. 関係の候補を残す

タグ、語彙一致、近傍クラスタ、発見候補を使って関係を探します。候補は自動的に意味リンクへ昇格しません。根拠を確認して、採用・却下・保留を選びます。

`@` では意味関係の相手を検索できます。未解決名から暗黙に項目やStubは作られません。必要なら `Shift+Enter` で未配置箱へ明示的に新規作成します。

## 3. 意味を確定する

`FROM`、`SUPPORT`、`VS` などの型を選んで意味関係を保存します。有向リンクでは方向も確認します。本文の内部参照 `[[` は不変IDを保持し、表示名の変更に影響されません。

## 4. 検索して再発見する

入力中はタイトルの厳密な前方一致候補を表示します。確定後は語彙一致、明示的なalias、グラフ上の近さを組み合わせ、順位の根拠も表示します。

発見タブでは、橋渡し、欠けたリンク、近傍クラスタの提案を確認できます。Queryタブでは読み取り専用のDatalog風クエリを実行できます。

```prolog
?- link("LIKE", From, To).
```

## 5. 長文へ編成する

長文編集では、アウトラインと本文を行き来しながら選択した思索を展開します。保存済みのRevisionやRecovery Snapshotは比較ペインで確認できます。完成した構成はMarkdownやOPMLへ出力し、最終校閲や組版を外部ツールへ渡せます。
