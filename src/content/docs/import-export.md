Radioraのデータを書き出す方法は、目的によって使い分けます。

## Markdown

現在のアウトラインを書き出します。参照の扱いを選べます。

| 形式 | 内容 |
| --- | --- |
| Radiora | 内部参照（`radiora://` の不変ID）を保持します。Radiora同士での持ち運び用 |
| ポータブル | 表示名だけを残します。外部ツールでの編集用 |
| Obsidian | 解決済みの参照を `[[表示名]]` のWikiリンクに変換します |

書き出す範囲は、アウトライン全体または選択した項目を基準に、祖先・配下・意味関係でつながる項目を含める範囲を選べます。

## OPML

アウトラインの階層と本文を、他のアウトライナーと交換するための形式です。階層と本文の交換用であり、項目の同一性、別稿、版、意味関係などのグラフ情報は完全には復元できません。

## 完全JSONバックアップ

Radioraの全状態（項目、配置、別稿、版、復元用保存、意味関係）を復元可能な形で保存します。ファイルには `format`、`schemaVersion`、`exportedAt`、`source`、`data` のenvelopeが付きます。

```json
{
  "format": "radiora-backup",
  "schemaVersion": 6,
  "exportedAt": "2026-08-06T00:00:00.000Z",
  "data": {}
}
```

### 復元するときの注意

- 復元は現在の全状態を置き換えます。実行する前に、現在のバックアップを書き出してください。
- 入力全体の検証に失敗した場合は、現在のデータは変更されません。空き容量とファイル内容を確認してからやり直してください。
- 現在のアプリより新しい形式のバックアップは、明示的に拒否され、部分的に読み込まれることはありません。

## 使い分け

- 外部ツールとの交換: Markdown（ポータブル）またはOPML
- Radioraの状態を丸ごと保存: 完全JSONバックアップ

Markdownだけでグラフ情報を完全に表現しようとせず、目的に合う形式を選びます。
