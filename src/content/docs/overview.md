Radioraは、日々の短いメモから長文の原稿までを同じ「項目」として保存できる、ローカル動作のアウトライナーです。項目の配置、項目どうしの意味関係、改稿の履歴を分けて管理し、別の草稿として分岐させることもできます。データはすべて手元のPCに保存されます。

## 主な流れ

1. 配置先を決めずに、思いついた内容をクイック入力で書き置く
2. アウトライン上で仮の位置に配置する
3. タグやリンクの候補を使って、関係の見当をつける
4. `FROM`、`SUPPORT`、`VS` などの意味関係で関係を確定する
5. 改稿するときは上書きせず、別稿や版として分岐させる
6. まとまった内容はMarkdownやOPMLで書き出し、外部ツールへ渡す

## 基本の考え方

### 配置と本文は別

同じ項目を複数の場所に配置しても、本文は複製されません。一つの内容を複数の文脈から参照・編集できます。

### 関係は後から決められる

インデントの位置は、包含なのか派生なのかをその場で決める必要はありません。仮の配置と、意味を確定するリンクを分けて扱います。

### 改稿は分岐

全面改稿は元の内容を上書きせず、別稿として分岐させます。破壊的な編集をしなくても、以前の状態と比較できます。

### 形式は役割ごとに分ける

MarkdownとOPMLは外部ツールとの交換用、完全JSONバックアップはRadioraの全状態の保全用です（[入出力とバックアップ](/docs/import-export)）。

## 用語

| 用語 | 意味 |
| --- | --- |
| 項目 | 本文をひとまとめにした単位。どの画面でも共通の「同じ内容」 |
| 配置 | 項目がアウトラインのどこに現れているか。場所ごとに階層と順序を持つ |
| 別稿 | 同じ項目から分岐した、進行中の別の本文 |
| 版 | ある時点の本文を確定して残した、変更できない履歴 |
| 意味関係 | 項目どうしの関係を型付きで記録したリンク |

データのモデルについて詳しくは[データモデル](/docs/data-model)を参照してください。
