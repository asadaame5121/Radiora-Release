## 意味関係を追加する

項目を選択して右側のインスペクター「関係」から `意味関係を追加` を選ぶか、`Ctrl+Shift+L` を押します。起点、種別、終点と向きを確認して保存します。

- 本文で `@` を入力すると相手の候補が開きます。項目を選んで関係型を選び、有向型では向きを決めて確定します。意味関係が作成され、入力した `@` と検索語は本文から取り除かれます。これは本文に参照を挿入する `[[` の内部参照とは別の操作です。
- 候補一覧で `Shift+Enter` を押すと、検索語を未配置項目として作成して関係の相手にできます。未解決の名前から項目やStubが暗黙に作られることはありません。
- 同じ名前の候補が複数ある場合は、表示情報を確認してから選択します。

高度な意味関係編集では、`起点 :: 種別 :: 終点` の形式でまとめて入力できます。3つの要素が解決するまで確定できません。種別は大文字小文字を問わず入力でき、保存時に正規化されます。

## 意味関係の種別

| 種別 | 意味 | 方向 |
| --- | --- | --- |
| `RELATED` | 関係がある | 対称 |
| `FROM` | ～から派生した | 有向 |
| `LIKE` | ～に似ている | 対称 |
| `SUPPORT` | ～を支持する | 有向 |
| `DEF` | ～を定義する | 有向 |
| `VS` | ～と対立する | 対称 |
| `FIX` | ～を修正する | 有向 |
| `CITE` | ～を引用する | 有向 |

`FROM` は保存の向き（新しいものが元を指す）と、ツリービューの世代表示（元から新しいものへ進む）で向きが変わります。

## カスタム関係型

Optionの「意味関係の種類」では、組み込みの型を確認し、有向または双方向のカスタム関係型を追加できます。有向型はツリーの世代を進める設定も選べます。カスタム型も本文の `@` 候補や関係編集で使用できます。

## 暗黙のFROM

異なるWorkをアウトライン上で親子に配置すると、同じWork間に有効な明示リンクがない場合、配置関係から暗黙の `FROM` が導出されます。これは保存された意味関係ではなく、現在のアウトラインから毎回計算されます。

意味関係一覧では暗黙のリンクに `（暗黙）` と表示されます。あとから明示的なリンクを作成すると、そのWork間では明示リンクが優先され、暗黙の `FROM` は追加されません。

## 本文中の意味関係候補

本文に `[[source::TYPE::target]]` と記述すると、別形式の意味関係候補として読み取られます。候補をクリックするとInspector「関係」で解決結果を確認できますが、確認だけでは関係は作成されません。

## 内部参照を挿入する

本文で `[[` を入力すると、項目または版の内部参照候補が表示されます。選択すると、不変IDを使う参照が本文に挿入されます。

- 参照は表示名ではなく不変ID（`radiora://`）で保存されるため、表示名を変更しても参照は維持されます。
- 右側の被参照一覧から、その項目を参照している本文へ移動できます。

## タグを使う

- 本文で `#タグ名` と書くとタグとして記録されます。先頭はUnicode文字、`_`、`-` のいずれかで、2文字目以降に文字、数字、`_`、`-`、`/` を使えます。数字だけのタグは認識されません。
- `\#` と書くと、`#` をタグにせず文字として扱います。コードブロック内やリンクURL内の `#` はタグとして認識されません。
- 入力中の補完、クリックによるフィルター、複数タグのAND検索と除外検索ができます。
- タグ一覧から、改名や統合、使用数の確認ができます。
- タグは別稿ごとに異なる内容を付けられます（例: 本稿に `#完成`、推敲中の別稿に `#執筆中`）。

## 候補は自動で確定されない

関係の候補（発見タブ）や重複候補は、自動では採用されません。根拠を確認してから、採用・却下・保留を明示的に選びます（[検索・発見・クエリ](/docs/search-discovery)）。
