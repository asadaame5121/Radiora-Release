## 表示を切り替える

ヘッダーの `Outline / Tree` で表示を切り替えます。Treeでは項目と意味関係を2D空間に投影して確認できます。

## 投影を選ぶ

| 投影 | X軸に使うもの |
| --- | --- |
| `Chronology` → `作成日時` | 項目の作成日時 |
| `Chronology` → `年表` | Inspector「概要」で設定した歴史上の時点・期間 |
| `Lineage` | 世代を進める設定の関係型に沿った世代 |

`Chronology`では`作成日時`と`年表`を切り替えられます。年表はWorkに明示設定した日付・年代・期間を使います。「今日」ビューで作成日・更新日ごとに項目を確認する表示とは別です。

世代を進める関係型の循環は世代計算から分離され、右端の `Knot` 列に退避して表示されます。投影を切り替えると、全体が収まるように表示が自動調整されます。

## ズームと移動

- マウスホイールまたは `+` / `-` で拡大・縮小します。最大で24倍まで拡大できます。
- ドラッグでパンできます。
- `全体を表示` で、内容全体が収まる位置と倍率に戻ります。

## 表示密度

表示密度に応じて `Detail / Context / Overview` が自動で切り替わります。

- **Overview**: 密集した場所は件数ノードにまとまります。件数ノードをクリックすると、その範囲へ拡大します。
- **Detail**: 個別の項目が表示されます。
- ノードにポインターを合わせると、直接つながっているノードとリンクだけが強調されます。
- 項目を選択すると、アウトライン上の祖先・子孫と `FROM` でつながる範囲が強調されます。選択中の項目を別の画面から開いても、同じWorkの代表ノードへ選択が引き継がれます。

## 右サイドバー

Tree表示では、右サイドバーが3つのタブになります。

| タブ | 内容 |
| --- | --- |
| 切り出し | 選択したクラスタの局所ツリーと項目一覧。一覧から項目を選択して実際の配置を開けたり、`中央で拡大` で構成ノードの範囲へ拡大できます |
| 表示中 | 昇格済みの別稿と版の一覧 |
| フィルター | ツリー全体の表示条件 |

## フィルターを設定する

`フィルター` タブでは、次の表示条件を変更できます。

- **孤立した項目を表示**: 選択中のリンク種別で他の項目とつながっていない項目を表示するかどうか（既定は表示）。
- **リンク種別**: `RELATED`、`FROM`、`LIKE`、`SUPPORT`、`DEF`、`VS`、`FIX`、`CITE`と登録済みカスタム関係型ごとに、表示する種別を切り替えられます。全選択・全解除もできます。

設定は保存され、次回起動時も維持されます。フィルター適用中は、ツリー上部に「表示件数/総件数」と有効な条件数が表示されます。
