## 表示を切り替える

ヘッダーの `Outline / Tree` で表示を切り替えます。Treeでは項目と意味関係を2D空間に投影して確認できます。

## 投影を選ぶ

| 投影 | X軸に使うもの |
| --- | --- |
| `Chronology` | 項目の作成時刻 |
| `Lineage` | `FROM` でつながる世代 |

`FROM` の循環は世代計算から分離され、右端の `Knot` 列に退避して表示されます。投影を切り替えると、全体が収まるように表示が自動調整されます。

## ズームと移動

- マウスホイールまたは `+` / `-` で拡大・縮小します。最大で24倍まで拡大できます。
- ドラッグでパンできます。
- `全体を表示` で、内容全体が収まる位置と倍率に戻ります。

## 表示密度

表示密度に応じて `Detail / Context / Overview` が自動で切り替わります。

- **Overview**: 密集した場所は件数ノードにまとまります。件数ノードをクリックすると、その範囲へ拡大します。
- **Detail**: 個別の項目が表示されます。
- ノードにポインターを合わせるかキーボードフォーカスすると、直接つながっているノードとリンクだけが強調されます。

## 右サイドバー

Tree表示では、右サイドバーが3つのタブになります。

| タブ | 内容 |
| --- | --- |
| 切り出し | 選択したクラスタの局所ツリーと項目一覧。一覧から項目を選択して実際の配置を開けたり、`中央で拡大` で構成ノードの範囲へ拡大できます |
| 表示中 | 昇格済みの別稿と版の一覧 |
| フィルター | ツリー全体の表示条件 |

## フィルターを設定する

`フィルター` タブでは、次の表示条件を変更できます。

- **孤立した項目を表示**: 選択中のリンク種別で他の項目とつながっていない項目を表示するかどうか（既定は表示）。
- **リンク種別**: `RELATED`、`FROM`、`LIKE`、`SUPPORT`、`DEF`、`VS`、`FIX`、`CITE` ごとに、表示する種別を切り替えられます。全選択・全解除もできます。

設定は保存され、次回起動時も維持されます。フィルター適用中は、ツリー上部に「表示件数/総件数」と有効な条件数が表示されます。
