## 項目を検索する

画面上部の検索欄を使います。

- 入力中は、タイトルの前方一致候補が表示されます。候補を `Enter` で開きます。
- 確定後は、語彙の一致、明示的な別名（alias）、グラフ上の近さを組み合わせて順位を付け、順位の根拠も表示します。
- 検索の結果表示は一時的な投影で、配置や本文、保存済みの状態を変更しません。

## 発見タブで関係の候補を確認する

項目を選択すると、右側の `発見` タブに関係の候補が表示されます。候補には次の種類があります。

- **橋渡し**: 2つの項目をつなぐ候補

## 重複候補を処理する

`重複候補` では、タイトル、別名、共有タグ、共有リンクの一致から、スコアと根拠が計算された候補を確認できます。候補ごとに次の操作を選べます。

| 操作 | 内容 |
| --- | --- |
| 統合する | 残す側を選んで、2つの項目を1つに統合します。配置、リンク、版、別名は保持されます |
| LIKEを作成 | 2つの項目を `LIKE` の意味関係でつなぎます |
| RELATEDを作成 | 2つの項目を `RELATED` の意味関係でつなぎます |
| 却下 | 何もしません |

## Queryを実行する

`Query` タブでは、項目とリンクに対する読み取り専用のDatalog風クエリを実行できます。利用できる述語は `item`、`parent`、`ancestor`、`link`、`title_prefix`、`text_match` です。

```prolog
?- link("LIKE", From, To).
```

- `Ctrl+Shift+Q` で実行します。
- 名前を付けて保存でき、後から再実行できます。
- 結果は表または投影表示（Sparse Outline）で確認できます。投影表示のノードを選ぶと、実際の項目を開きます。
- Queryは読み取り専用です。本文や配置、意味関係を変更しません。
